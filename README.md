# BBB Voting Challenge

Desafio técnico desenvolvido para a Laager.

## Objetivo

Construir um sistema de votação para o paredão do BBB capaz de suportar alto volume de votos, disponibilizando resultados em tempo real e métricas de monitoramento.

## Stack

### Backend

- Ruby on Rails API
- PostgreSQL
- Redis
- Sidekiq
- RSpec

### Frontend

- HTML
- CSS
- JavaScript

### Infraestrutura

- Docker Compose
- Prometheus
- Grafana

## Arquitetura

A arquitetura será orientada a alta disponibilidade e baixa latência, utilizando Redis para contadores em tempo real e processamento assíncrono para persistência dos votos.
